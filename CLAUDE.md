# Card Finder

A Safari Web Extension (Mac + iPad) that checks local game stores' TCGplayer Pro storefronts for cards tagged as unowned in Moxfield decks. A Node crawler builds `data/storefronts.json` (the storefront directory) weekly.

## Commands

These are the same commands CI runs (`.github/workflows/ci.yml`, Node 24):

```sh
npm ci
npm run lint         # ESLint + Prettier check (`npm run format` fixes formatting)
npm run typecheck    # extension, tests and crawler tsconfigs
npm test             # Vitest, no network
npm run build        # bundle into dist/ (`npm run dev` rebuilds on change)
npm run crawl -- --zip <zip> --miles <n> --marketplace-products 0 --data <scratch dir>
```

Use the `crawl` form above for local crawler tests: it covers one area, skips the marketplace pass, and writes to a scratch directory instead of `data/`. It makes live requests, so don't run it in tests.

## Layout

- `src/lib/`: platform-neutral logic, unit-tested
- `src/background/`, `src/content/`, `src/options/`, `src/popup/`, `src/results/`: extension entry points (service worker, Moxfield content script, settings page, toolbar popup, results page); `src/ui/`: shared UI code
- `src/crawler/`: Node-only crawler (own `tsconfig.json`); must not be imported by extension code
- `static/`: manifest, HTML, CSS, icons, copied into `dist/`
- `tests/`: Vitest tests with recorded fixtures in `tests/fixtures/`
- `data/`: generated by the crawler, never hand-edit
- `docs/spikes/`: API investigation notes

## Conventions

- Tests use recorded fixtures and a fake `fetch`, never the live network.
- Requests to storefronts must send a browser-like User-Agent without the words "crawler" or "bot", because the storefront firewall blocks them (`CRAWLER_USER_AGENT` in `src/crawler/http.ts`).
- Generated `data/` is excluded from Prettier (`.prettierignore`).
- Keep the Xcode project out of hand edits: it is generated into `xcode/` by `scripts/create-xcode-project.sh`.

## External APIs and gotchas

- TCGplayer Pro storefront API: `docs/spikes/tcgplayerpro.md`.
- Store discovery (Wizards store locator, Common Crawl seeds): `docs/spikes/store-discovery.md`.
- Moxfield blocks requests from servers, so the crawler never touches it. The extension reads decks and tags in the user's own browser.
